# 🧮 Projeto de Análise de Dados — SQL (Olist)

## 📌 Visão Geral
Este projeto tem como objetivo analisar dados de um e-commerce brasileiro
utilizando SQL, com foco em consultas analíticas, métricas de negócio
e geração de insights a partir de dados relacionais.

## 🗂️ Dataset
Fonte: Brazilian E-Commerce Public Dataset by Olist  
Formato: CSV  
Período: 2016–2018

## 🎯 Objetivos da Análise
- Explorar dados transacionais com SQL
- Responder perguntas de negócio
- Demonstrar domínio de JOINs, agregações e análises temporais

## 🛠️ Ferramentas
- MySQL
- SQL
- Git & GitHub
